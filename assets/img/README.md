# Assets de marca e imagem

Use somente arquivos oficiais ou previamente aprovados.

Arquivos esperados:
- `bni-logo-red.svg` ou equivalente oficial: logo BNI vermelho para fundos claros.
- `bni-logo-white.svg` ou equivalente oficial: versão branca reversa para fundos vermelhos/escuros.
- `campos-regiao-hero.jpg`: fotografia real/aprovada de Campos dos Goytacazes ou da região.

Regras:
- Não distorcer, recolorir, aplicar sombra, contorno ou filtros ao logo.
- Não usar skyline genérico ou imagens de outra cidade para representar Campos dos Goytacazes.
- Enquanto não houver fotografia aprovada, o site usa apenas composição abstrata com a paleta oficial BNI.
- Sempre incluir texto alternativo descritivo em imagens informativas.
