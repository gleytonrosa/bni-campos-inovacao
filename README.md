# BNI Campos Inovação

Single Page institucional da BNI Campos Inovação, criada para apresentar a proposta da equipe e direcionar empresários interessados para uma visita via WhatsApp.

## Estrutura

- `index.html` — conteúdo e estrutura semântica.
- `assets/css/styles.css` — sistema visual responsivo baseado na paleta oficial BNI.
- `assets/js/main.js` — menu mobile e centralização do link de WhatsApp.
- `assets/img/README.md` — regras para inclusão de logo e fotografia aprovados.
- `.nojekyll` — compatibilidade com publicação estática no GitHub Pages.

## Identidade visual

Paleta utilizada:
- BNI Red `#CF2030`
- True White `#FFFFFF`
- Power Black `#000000`
- Sterling Grey `#C8C8C8`
- Granite Grey `#64666A`
- Sterling Light Grey `#F2F2F2`

Não introduzir paleta paralela e não alterar a logomarca oficial da BNI.

## Conversão

Todos os CTAs usam o WhatsApp oficial da BNI Campos Inovação: `(22) 92550-0775`.

## Publicação

O site foi preparado para GitHub Pages a partir da raiz do repositório. Após integração na `main`, configure em **Settings → Pages** a origem como **Deploy from a branch**, branch `main`, pasta `/ (root)`.

URL esperada após ativação:
`https://gleytonrosa.github.io/bni-campos-inovacao/`

## Atualização de imagens

Somente use fotografias reais/aprovadas de Campos dos Goytacazes e arquivos oficiais da marca BNI. Consulte `assets/img/README.md` antes de substituir os placeholders visuais.
